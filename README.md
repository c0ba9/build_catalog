# 🏠 СтройМаркет — Интернет-магазин строительных и кровельных материалов

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Django](https://img.shields.io/badge/Django-4.x-092E20?style=for-the-badge&logo=django&logoColor=white)
![Frontend](https://img.shields.io/badge/Frontend-HTML5%2FCSS3%2FJS-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![Лицензия](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

Веб-приложение для онлайн-каталога и интернет-магазина, разработанное на Django. Проект предназначен для компаний, специализирующихся на продаже кровельных материалов (металлочерепица, гибкая черепица), сайдинга, ограждений, водосточных систем и строительных инструментов.

---

## ✨ Основные возможности

- **Динамическая архитектура каталога**: Поддержка иерархической структуры категорий (родительские и подкатегории) с иконками и бейджами.
- **Управление товарами**: Подробный просмотр товаров с динамическими атрибутами (цена за $м^2$ или штуку, статусы наличия, метки под заказ, галерея изображений и подробные описания).
- **Витрина популярных товаров**: Интерактивная главная страница с блоками рекомендуемых товаров и категорий.
- **Кастомная панель администратора**: Настроенная админ-панель Django (`acme-admin`) с индивидуальным стилем для удобного управления сайтом.
- **Адаптивный интерфейс**: Современный удобный дизайн с поддержкой мобильных устройств, каруселей товаров (`slick`) и гибкой навигацией.
- **Информационные страницы**: Готовые шаблоны для страниц «О компании», «Доставка и оплата» и «Контакты».

---

## 🛠️ Технологический стек

- **Бэкенд**: Python, Django
- **База данных**: SQLite (по умолчанию для разработки), совместимо с PostgreSQL / MySQL
- **Фронтенд**: HTML5, CSS3, JavaScript, jQuery, Slick Carousel, Font Awesome
- **Конфигурация**: `python-dotenv` для управления переменными окружения

## 📂 Структура проекта

```text
├── catalog/                # Основное приложение каталога товаров
│   ├── migrations/         # Миграции базы данных
│   ├── admin.py            # Настройки админ-панели
│   ├── models.py           # Модели категорий, товаров и изображений
│   ├── views.py            # Логика отображения и маршрутизация
│   └── context_processors.py # Глобальные контексты шаблонов
├── config/                 # Основные настройки проекта и URL
│   ├── settings.py         # Настройки Django и секретные ключи
│   ├── urls.py             # Корневая маршрутизация URL
│   └── wsgi.py / asgi.py   # Файлы для деплоя
├── static/                 # Статические файлы (CSS, JS, шрифты, изображения)
├── templates/              # HTML-шаблоны (каталог, страницы, базовый макет)
├── .env.example            # Пример файла переменных окружения
├── manage.py               # Скрипт управления Django
└── requirements.txt        # Зависимости проекта
```

## 🚀 Быстрый старт

### Требования

Убедитесь, что на вашем компьютере установлены:
- **Python 3.10+**
- **pip** (менеджер пакетов Python)
- **git**

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. **Создайте и активируйте виртуальное окружение:**
   - **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   - **Windows:**
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка переменных окружения:**
   Скопируйте `.env.example` для создания локального файла `.env`:
   ```bash
   cp .env.example .env
   ```
   *При необходимости обновите секретные ключи и параметры отладки в `.env`.*

5. **Примените миграции:**
   ```bash
   python manage.py migrate
   ```

6. **Создайте учетную запись администратора:**
   ```bash
   python manage.py createsuperuser
   ```
   Следуйте инструкциям в терминале, чтобы ввести логин, email и пароль.

7. **Запустите сервер разработки:**
   ```bash
   python manage.py runserver
   ```

8. **Откройте приложение:**
   Перейдите в браузере по адресу `http://127.0.0.1:8000/`.  
   Админ-панель доступна по адресу `http://127.0.0.1:8000/admin/`.
